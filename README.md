# In Vivo Data-Driven Aortic Pressure Estimation from Electrical Impedance Tomography

This branch contains the code related to the paper *In Vivo Data-Driven Aortic Pressure Estimation From Electrical Impedance Tomographic Measurements* for predicting systolic arterial pressure (SAP), mean arterial pressure (MAP),
and diastolic arterial pressure (DAP) using electrical impedance tomography (EIT) measurements.
